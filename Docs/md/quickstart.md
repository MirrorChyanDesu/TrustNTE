\## 前置准备

第一步，启动原神客户端，确认并   改下面两项设置：



1\. \*\*游戏语言\*\*

&#x20;   游戏语言必须设置为 \*\*简体中文\*\*，暂不支持其他语言。

&#x20;   > The game language only supports Simplified Chinese.



2\. \*\*游戏分辨率\*\*

&#x20;   推荐：`1920 × 1080`，全屏 / 窗口化均可。

&#x20;   > 使用该分辨率可以支持软件全部功能；大部分功能在其他 16:9 分辨率下也可以正常工作。
