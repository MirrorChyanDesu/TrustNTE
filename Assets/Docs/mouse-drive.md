# 🖱️ 鼠标驱动方式 - 选择说明

三种点击方式的区别，选错会导致点不动、或打扰你正常用电脑。

### 🖐️ 物理点击 (万能)

- 强行把游戏拉回前台，并移动你的真实鼠标去点击
- 兼容性最强，什么都点得动
- **代价**：玩其他游戏 / 看视频时会被打断

### 🖱️ 通用点击（推荐）

- 前后台都能用：游戏在前台能点，切到后台也能点
- 原理：伪造焦点并发送底层扫描码
- 不抢前台、不乱动鼠标，绝大多数场景都适用
- **并无注入 DLL！安心使用**

### 🌐 后台点击 (可能失效)

- 纯后台发送窗口消息，鼠标完全不动
- 防干扰最佳，适合一边挂机一边干别的
- **缺点**：异环引擎容易屏蔽这种方式（表现为点了没反应）

### 💡 建议

不同电脑环境表现可能不同，前往本页下方【按键与点击测试区】实际测一下，哪种点得动、不打扰你，就用哪种。
