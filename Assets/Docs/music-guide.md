# 音游参数配置指南

> **⚠️ 注意**
> 要达到 100% 准确率，请前往【启动】界面，将截图引擎的 [抓帧间隔](app://goto-interval) 改为 **15 ~ 30** 之间（根据自己电脑 CPU 和 GPU 合理调试即可）。

### <span style="color: #f60101;">🔴注意</span>
- **把截图间隔改为10~30微调或者把选择物理点击 游戏窗口置于前台。选其他键鼠是消息的形式传递会漏键！图集会自动识别开始/演奏/结算。&#10;为了增强鲁棒性→成功率！功能启用的是4线程！可同时触发四个键！不要把抓帧间隔调至10可能会适得其反！！
### 1. 触发与复位 (最核心调参区)
- **触发像素**：判定圈里出现了多少个特征点（黑块或音符色）就按键。漏键就调小（如 10）；乱按就调大（如 20）。
- **复位像素**：打完字，像素降到多少算这个音符“走远了”。防连按调大（如 5）；极速连打调小（如 1）。
- **强制复位 ms**：超时强行解锁，防止白圈太长久挡住画面卡死。连打总漏就调小（如 80），总是碰按就调大（如 150）。
- **V≤**：多暗的颜色才算“黑色特效”。0 是纯黑，255 是纯白，推荐 30~80。

### 2. 响应与间隔 (手感调节)
- **间隔 ms**：两次按键的最短冷却时间。调太大会漏音，调太小容易卡顿（推荐 15~40）。
- **按住 ms**：模拟键盘按住的时间。太短（<5ms）有的游戏会判定无效吞键（推荐 15~25）。
- **半径**：判定圈的大小。调大会把远处的音符也框进来，调小更精准。

### 3. 判定圆心与调试
强烈建议打歌时打开【调试画面】，用鼠标拖动画面的四个绿圈（对应 **D、F、J、K** 的判定正中心）。滚轮可以调大字号。

> **💡 提示**
> 本程序采用“纯黑特征”+“底色消失”+“特定音符色”三重防漏键判定，只要画面中出现了特征，就会触发按键。
