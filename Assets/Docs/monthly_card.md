# 自动领取月卡/环石 - 工作原理

为了最大程度减少对游戏性能和挂机任务的影响，本模块采用了 **"独立闹钟"** 机制：

## ⏰ 模式一：全天启用

- 开启后，后台每隔几秒静默扫描一次画面。
- 发现月卡图标自动点击，领取成功后自动休眠至明天。

## 🕒 模式二：指定时间段

- 在开始时间前，处于深度休眠，不抓取画面。
- 到点自动唤醒开始扫描，到结束时间强制关闭。

## 🌐 时间基准

| 时间类型 | 适用服务器 | 说明 |
| :--- | :--- | :--- |
| 本地时间 | 国际服 | 游戏在当地凌晨刷新 |
| 北京时间 | 国服 | 强制对齐 UTC+8 凌晨 4 点刷新 |
