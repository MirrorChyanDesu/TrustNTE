快捷键使用指南

TrustNTE 的所有功能都可以绑定键盘快捷键。本文说明快捷键的工作方式、两种模式的区别、冲突处理规则，以及使用中的常见问题。

设置入口： 侧边栏 → 快捷键设置。所有功能出厂时均为未绑定状态，按需自行设置。

一、两种工作模式

每个快捷键都可以在两种模式中选择，区别在于按下时按键会不会被“截走”：

底层监听（默认） 全局独占
按键去向 TrustNTE 和游戏同时收到 只有 TrustNTE 收到，游戏收不到
对游戏的影响 无影响（可能双方同时动作） 该按键在游戏中的功能失效
适合场景 与游戏按键不冲突的功能 明确不会在游戏内使用的按键
冲突提示 日志记录 弹窗确认，取消则不生效
简单记：底层监听是“旁听”，全局独占是“抢线”。不确定就用底层监听，它永远不会弄坏游戏里的按键功能。

二、如何绑定、修改、清空

  1. 绑定：点击绑定框，框内出现光标后直接按下想用的按键（支持 Ctrl / Alt / Shift / Win 组合，如 Alt+Q）。
  2. 修改：直接重复上面的步骤，新按键会覆盖旧按键。
  3. 清空：绑定框获得焦点时按 Delete、Backspace 或 Esc，恢复为 < None >。

单独按下修饰键（Ctrl、Alt、Shift、Win）、Tab 等不会被视为绑定。

绑定时的特殊状态

绑定框获得焦点期间，软件进入录入模式：

  • 所有已注册的全局独占热键临时挂起——因此即使某个键已经被别的功能全局占用，你也能把它录入到新的位置；
  • 录入期间所有快捷键功能暂停触发——放心按 F1，引擎不会因此启停；
  • 点击别处（绑定框失去焦点）后，全局热键立即按当前绑定恢复。

三、冲突处理规则

1. 软件内部冲突：后绑获胜

同一个按键只能属于一个功能。把 A 键绑给新功能时，原本绑着 A 的旧功能会自动清空，日志中会出现一条记录。

与游戏按键冲突

2. 与游戏按键冲突

异环内置了一批功能按键。TrustNTE 维护了一份占用表，你绑定这些键时会得到提醒（底层监听 → 日志记录；全局独占 → 弹窗确认）。

“未收录”是什么意思？
这些键不在 TrustNTE 的占用表里，绑定时不会收到提醒——但这不代表游戏一定没有使用它们。游戏版本更新可能新增按键功能，绑定前建议先在游戏里试一下。最稳妥的选择：组合键（如 Alt+Q）不会与任何游戏单键冲突。

处理方式按模式不同：

  • 底层监听：只写一条日志提醒，绑定立即生效。按下时游戏功能和 TrustNTE 会同时触发，属于预期行为；
  • 全局独占：弹出确认框。选确定 → 绑定生效（游戏内该键失效）；选取消 → 新绑定和被抢占的旧绑定都会自动恢复原样。
