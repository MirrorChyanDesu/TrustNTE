# 🖥️ 各截图引擎的差异对比

### ① PrintWindow（推荐首选）

- **核心优势**：微软预留的后台截图神级后门 (PW_RENDERFULLCONTENT)。
- **适合场景**：异环等 3D 游戏的后台挂机。不抢焦点，画面稳如泰山。
- **全屏窗口**：全屏和窗口化都能用！选择这个没问题。

### ② WGC (Windows Graphics Capture)

- **核心优势**：微软现代 API，但在原生 C# 下调用极容易因混合显卡或系统环境黑屏。
- **适合场景**：主流现代 3D 游戏。

### ③ DXGI (Desktop Duplication)

- **核心优势**：极高效率的后台截图。
- **适合场景**：WGC 失效时的最佳备选方案。

### ④ BitBlt

- **核心优势**：兼容性最强。
- **适合场景**：抓取 2D 软件、启动器等传统窗口。3D 游戏后台抓取易黑屏。

### ⑤ DWM

- **核心优势**：系统桌面窗口管理器抓取。
- **适合场景**：带有特殊透明特效的普通窗口。
